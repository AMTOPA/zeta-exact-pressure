# Lineage

This repository continues the following research chain:

1. **Anthropic** — explicit-formula / trace framework and the unconditional two-thirds-scale simple-zero result.
2. **`ainta/zeta-simple-zeros`** — stability / Gram refinements.
3. **`trmdy/zeta-simple-zeros-673137`** — re-optimized window and stronger local finite-dimensional input.
4. **`sxuff/zeta-positioned-pressure`** — position-dependent pressure certificate.
5. **`AMTOPA/zeta-exact-pressure-673262`** — exact shifted-block pressure multiplicity, replacing the coarse global pressure factor.
6. **This repository** — keeps exact pressure averaging and re-optimizes the analytic window against the final exact-pressure objective.

The numerical comparisons in the README are not claims of independent peer-reviewed status. They are research-draft milestones under a shared analytic interface.
